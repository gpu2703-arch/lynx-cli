# Lynx Sharp CLI

Одна команда — всё необходимое для разработки.

```powershell
iwr -useb https://lynx.sh/install.ps1 | iex
```

## Команды

| Ввод | Что делает |
|------|-----------|
| `lynx install` | Установка dev tools (node, git) |
| `lynx install ai` | + ML пакеты (torch, numpy) |
| `lynx upgrade` | Обновить lynx |
| `lynx chat` | Чат с ИИ |
| `lynx -v` | Версия |
